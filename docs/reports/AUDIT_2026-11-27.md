# Audit avant passage du dépôt en public (2026-11-27)

Objectif : rendre le dépôt GitHub public sans risque et le présenter comme une vitrine de la méthode de travail (code, gouvernance, usage cadré de l'IA).
Périmètre : historique Git, code Laravel, site en production (https://www.jeremyescassut.com), dépendances, référencement.

Légende des priorités : **P1** bloquant avant ouverture, **P2** à faire rapidement, **P3** amélioration.

## 3. Référencement (SEO)

Pertinent ici : le site est surtout partagé par lien (LinkedIn, e-mail), et l'aperçu affiché à ce moment-là est la première impression.

| # | Constat | Action | Priorité |
|---|---------|--------|----------|
| SEO-1 | Aucune balise Open Graph / Twitter : un lien partagé sur LinkedIn s'affiche sans image ni description maîtrisées. | Titre, description, image d'aperçu (1200×630), langue, URL. | P1 |
| SEO-2 | Pas de `rel="canonical"` : la même page d'accueil répond sur `/` et `/fr`. | URL canonique par page. | P2 |
| SEO-3 | Pas de liens `hreflang` entre les versions FR et EN. | `hreflang="fr"`, `"en"` et `"x-default"` sur chaque page. | P2 |
| SEO-4 | Pas de `sitemap.xml` ; `robots.txt` autorise tout mais ne le référence pas. | Générer le sitemap (6 URL) et le déclarer dans `robots.txt`. | P2 |
| SEO-5 | Pages inconnues servies avec un code 200 (« soft 404 », voir P-5). | Vraie 404. | P2 |
| SEO-6 | 4 titres `<h1>` sur l'accueil (le nom, plus 3 fenêtres : vidéo, contact, CV). | `<h2>` dans les fenêtres. | P3 |
| SEO-7 | Titre de page identique partout (« Portfolio - Jérémy Escassut ») et données structurées absentes. | Titre propre à chaque page ; données `Person` (schema.org) sur l'accueil. | P3 |
