# Dossier `public/cv/`

Placez ici vos fichiers PDF de CV. Recommandations :

-   Nom de fichier : `prenom-nom-vX.Y.pdf` ou `cv-v0.1.pdf` pour historiser.
-   Si vous voulez un lien stable depuis l'interface, ajoutez ou mettez à jour `cv.pdf` comme fichier principal (ex: `cv.pdf` -> lien public `/cv/cv.pdf`).
-   Évitez de committer des fichiers très volumineux fréquemment; si vous mettez à jour souvent, envisagez un stockage externe (S3, GitHub Releases, etc.).

Exemples :

-   `public/cv/jeremy-escassut-v0.1.pdf`
-   `public/cv/cv.pdf` (copie pointant vers la version courante)

Accès local : `http://localhost:8000/cv/cv.pdf` (si `php artisan serve`) ou `https://votre-site/cv/cv.pdf` en production.
